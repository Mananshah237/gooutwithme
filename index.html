Managed Agents

Deploy headless agents for scheduled, automated legal workflows. Run them on a cron behind your own workflow engine.

renewal-watcher
Weekly
Scans contract register for cancel-by deadlines within 90 days. Posts digest to Slack or email.
docket-watcher
Daily
Monitors court dockets for new filings, orders, and deadlines across active matters.
reg-monitor
Weekly
Sweeps regulatory feeds for new rules, amendments, and enforcement actions in your practice areas.
launch-radar
Weekly
Watches product roadmap for upcoming launches that need legal review — flags before engineering ships.
diligence-grid
On-demand
Monitors VDR for new document uploads during M&A diligence, triages by issue type, updates the grid.

Deploy a managed agent:

export ANTHROPIC_API_KEY=sk-ant-... scripts/deploy-managed-agent.sh reg-monitor

Get Started in 60 Seconds

  1. Install Claude Desktop and get access to Claude Cowork
  2. Click Customize → Browse plugins
  3. Search for claude-for-legal and install your practice area plugin
  4. Restart Claude Desktop
  5. Run /<plugin>:cold-start-interview to configure your practice profile
  6. Connect research tools: /<plugin>:cold-start-interview --check-integrations
Important: Choose user scope (not project scope) when installing. Project scope blocks the plugin from reading files outside the project folder — your outlines in Downloads, your contract in Documents, your client file in Dropbox.
  1. Open Claude Code in your terminal
  2. Add the marketplace:
/plugin marketplace add https://github.com/anthropics/claude-for-legal
  1. Install your practice area plugin:
/plugin install commercial-legal@claude-for-legal
  1. Run the setup interview:
/commercial-legal:cold-start-interview
  1. Set your Anthropic API key:
export ANTHROPIC_API_KEY=sk-ant-...
  1. Validate all cookbooks:
bash scripts/test-cookbooks.sh
  1. Deploy an agent:
scripts/deploy-managed-agent.sh renewal-watcher

Design Principles

🎯

Practice Profile-Driven

Every plugin starts with a cold-start interview that learns your specific playbook. Subsequent skills reference your profile for jurisdiction-aware, calibrated output.

🛡️

Attorney Review Gate

Explicit gates before anything is filed, sent, or relied on. Conservative defaults on privilege and subjective legal calls. Over-flagging is a two-way door; under-flagging is a one-way door.

📍

Source Attribution

Every citation includes provenance and verification status. [Westlaw], [CourtListener], [model knowledge — verify]. The tag describes what happened, not what you'd like to claim.

🌍

Jurisdiction Recognition

Skills detect non-US jurisdictions and adapt or surface gaps. A confident wrong answer using the wrong jurisdiction's law is worse than "I don't know."

⚡

No Build Step

Everything is markdown and JSON. Works in Claude Cowork, Claude Code, and as managed agents. No webpack, no npm install, no configuration dance.

🔐

Prompt Injection Defense

Retrieved content from contracts, case text, or documents is DATA — not instructions. Embedded directives in retrieved content are flagged, not executed.
