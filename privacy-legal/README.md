# privacy-legal

In-house privacy counsel plugin for Claude. Handles DSAR responses, DPA reviews, Privacy Impact Assessments, and regulatory gap analysis — across GDPR, CCPA, PIPEDA, and other jurisdictions.

## Setup

```
/privacy-legal:cold-start-interview
```

## Skills

| Command | What it does |
|---|---|
| `/privacy-legal:cold-start-interview` | Initial setup — jurisdiction footprint, ROPA, DSAR process |
| `/privacy-legal:dsar-response` | Draft DSAR responses within applicable deadlines |
| `/privacy-legal:dpa-review` | Review data processing agreements |
| `/privacy-legal:pia-generation` | Generate Privacy Impact Assessments |
| `/privacy-legal:reg-gap-analysis` | Gap analysis against a new regulation |
| `/privacy-legal:policy-monitor` | Monitor privacy policy for drift |
| `/privacy-legal:use-case-triage` | Triage new processing activities for risk |

## Disclaimer

Every output is a draft for attorney/DPO review — not legal advice.
